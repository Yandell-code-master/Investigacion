Bienvenido a BigFOOD Services

BigFOOD Services es una aplicación web desarrollada bajo una arquitectura desacoplada utilizando Angular para el frontend y ASP.NET Core Web API para el backend. El sistema permite gestionar información comercial mediante módulos independientes que se comunican a través de servicios HTTP.

La aplicación implementa operaciones CRUD para la administración de clientes, productos y facturas, utilizando una base de datos SQL Server y Entity Framework para el acceso a los datos. Esta separación entre interfaz y lógica de negocio facilita el mantenimiento, la escalabilidad y la reutilización de los componentes del sistema.

A través de los módulos disponibles, es posible consultar, registrar, actualizar y eliminar información de manera dinámica, aprovechando las ventajas de una Single Page Application (SPA) desarrollada con Angular.
